# Illusion Interactive

Static studio website for GitHub Pages. No install or build step is needed.

## Local preview

From the repository root:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000 and refresh after editing.

Studio styling is shared through `assets/studio.css`. The game page keeps its own theme. Brand asset notes are in `assets/brand/README.md`.
